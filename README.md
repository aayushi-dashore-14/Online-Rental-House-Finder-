# Online Rental House Finder

## 1. Project Overview
Online Rental House Finder is a web-based application developed to help users find and view rental house information.

## 2. Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, JSP
- **Database:** MySQL
- **Database Connectivity:** JDBC

## 3. Prerequisites
- Java JDK
- NetBeans IDE
- MySQL Server
- MySQL JDBC Driver
- Git

## 4. Clone Repository

```bash
git clone https://github.com/aayushi-dashore-14/Online-Rental-House-Finder-.git
```

Navigate to the project folder:

```bash
cd Online-Rental-House-Finder-
```

## 5. Setup Instructions

1. Open NetBeans IDE.
2. Select **File → Open Project**.
3. Choose the cloned project folder.
4. Start the MySQL server.
5. Create the required database.
6. Import the `rentalhouse.sql` file into MySQL.
7. Configure the JDBC connection with your database URL, username and password.
8. Ensure the MySQL JDBC driver is added to the project libraries.

## 6. Run the Application

1. Open the project in NetBeans.
2. Select **Clean and Build**.
3. Click **Run Project**.
4. Open the local application URL in your browser.

## 7. Database
The project uses MySQL to store rental house information. The database script is provided in `rentalhouse.sql`.
