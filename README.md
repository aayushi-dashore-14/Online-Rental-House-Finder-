# Online Rental House Finder

## About the Project
Online Rental House Finder is a web-based application that helps users find and manage rental house information.

## Technologies Used
- HTML
- CSS
- JavaScript
- Java
- JSP
- JDBC
- MySQL

## Key Features
- Displays rental house information.
- Provides a web-based interface for users.
- Uses Java and JSP for dynamic web pages.
- Connects to MySQL database using JDBC.

## Database
The project includes `rentalhouse.sql` for the database.
